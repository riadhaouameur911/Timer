# ⏱️ Timer

A simple timer application built with **HTML**, **CSS**, and **JavaScript**.

This project allows users to start, pause, and reset a timer while displaying hours, minutes, and seconds in real time.

## ✨ Features

- ▶️ Start the timer
- ⏸️ Pause the timer
- 🔄 Reset the timer
- 🕒 Display hours, minutes, and seconds
- 🚫 Prevent multiple intervals from running at the same time
- 🎨 Modern and responsive UI

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (DOM)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/riadhaouameur911/Timer.git
```

### Navigate to the project

```bash
cd timer
```

### Run the project

Open `index.html` in your browser.

## 🎮 Usage

- **Start** → Start the timer.
- **Pause** → Pause the timer.
- **Reset** → Reset the timer to `00:00:00`.
